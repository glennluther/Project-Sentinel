# Project-Sentinel

A software assurance platform designed to harden applications and help make them enterprise ready.

### Technology

`TypeScript` · `SQLite` · `Static Analysis` · `Security` · `Developer Tooling`

Sentinel evaluates repository health, architecture, security, code quality, and engineering risk through repeatable automated checks, then turns those findings into traceable reports developers can act on.
